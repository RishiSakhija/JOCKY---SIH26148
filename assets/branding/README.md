## Logo Concept (Planned)

**Symbol**: Interlocking chain links forming a "J" — representing evidence chains, contracts, and investigation links.

**Variants**:
- Full lockup (symbol + wordmark)
- Symbol only (favicon, app icon)
- Horizontal (headers)
- Vertical (stacked layouts)

## Usage Guidelines (Planned)

| Do | Don't |
|----|-------|
| Use approved colors | Modify colors |
| Maintain clear space | Stretch/distort logo |
| Use on appropriate backgrounds | Use on busy backgrounds |
| Use SVG for scaling | Use low-res PNG |
| Include attribution | Claim endorsement |
