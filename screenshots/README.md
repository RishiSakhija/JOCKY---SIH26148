### Technical Specs
- **Format**: PNG (lossless)
- **Resolution**: 1920x1080 (desktop), 375x667 (mobile)
- **DPI**: 72
- **Color**: sRGB
- **No sensitive data**: Use synthetic/demo data only

### Capture Process
1. Run JOCKY with demo case
2. Navigate to target page
3. Capture full viewport (browser dev tools → device toolbar)
4. Save to `screenshots/`
5. Update README.md with new images
